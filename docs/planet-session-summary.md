## 4. APIs التي تم بناؤها

### أ. البحث عن المشاهد
```
GET /api/v1/satellite/planet-scenes
  ?bbox=minLon,minLat,maxLon,maxLat
  &date_from=YYYY-MM-DD
  &date_to=YYYY-MM-DD
  &max_cloud=0.3
  &limit=20
  &item_type=PSScene

النتيجة: قائمة بالمشاهد المتاحة مع بيانات كل مشهد
```

### ب. جلب الصورة المصغّرة (256×256)
```
GET /api/v1/satellite/planet-thumbnail
  ?scene_id=...
  ?item_type=PSScene

يتحقق أولاً من الأرشيف المحلي ← ثم يجلب من Planet
يعمل حتى بعد انتهاء الاشتراك (من الكاش المحلي)
```

### ج. كشف التغييرات
```
POST /api/v1/satellite/planet-detect
{
  "bbox": [minLon, minLat, maxLon, maxLat],
  "date_baseline": "2026-06-01",
  "date_current": "2026-07-08",
  "detection_mode": "change"
}

النتيجة: مقارنة مشهدين + تصنيف التغيير + نسبة الثقة
```

### د. نظام الأرشيف (الجديد)
```
GET  /api/v1/satellite/planet-archive          → قائمة المشاهد المؤرشفة
POST /api/v1/satellite/planet-archive          → أرشفة منطقة جديدة
DELETE /api/v1/satellite/planet-archive?id=... → حذف مشهد
```

## 8. المقترح التالي — نظام مراقبة تقدم المشاريع

### الهدف:
إثبات أن مراقبة الأقمار الاصطناعية تُغني عن المتابعة الميدانية في رصد تقدم مشاريع الدولة.

### المكونات المقترحة:
1. **خريطة المشاريع** — مضلعات ملوّنة بالحالة (نشط/متوقف/مكتمل)
2. **بطاقة التحليل** — جدول زمني + نسبة إنجاز + فترات التوقف
3. **محرك Activity Score** — يقارن صور Planet تلقائياً لكل فترة
4. **التنبيهات** — تنبيه عند توقف العمل أكثر من X يوم
5. **لوحة KPIs** — إحصاء شامل لكل المشاريع
6. **أدوات متقدمة** — مقارنة بالشريط، Animation زمنية، تقرير PDF

### خطة التنفيذ:
```
المرحلة 1 (أسبوع 1): إنشاء المشاريع + عرض على الخريطة
المرحلة 2 (أسبوع 2): محرك التحليل (Activity Score + كشف التوقفات)
المرحلة 3 (أسبوع 3): التنبيهات + تقارير PDF/Excel
المرحلة 4 (أسبوع 4): مقارنة بالشريط + Animation + كشف نوع النشاط
```
