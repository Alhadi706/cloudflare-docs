### 1.2 🔍 السبب الجذري — Bug في تصفية الـ Scenes

**الخطأ البرمجي:**
```typescript
// ❌ الكود القديم (خاطئ)
let sceneBbox: number[] = meta.bbox ?? [];
if (sceneBbox.length !== 4 && meta.geometry?.coordinates?.[0]) {
  // ...
}
```

**المشكلة**: `meta.bbox` في بيانات أرشيف Planet هو **bbox تقريبي للمنطقة الكاملة** وليس للمشهد الفعلي.

**مثال:**
```
scene: 20260708_094921_19_2555
meta.bbox (مخزون): [12.8, 32.6, 13.5, 33.1]  ← كل منطقة طرابلس!
geometry-derived bbox (الحقيقي): [13.289, 32.982, 13.703, 33.233]  ← الموقع الفعلي

نتيجة: الكود القديم يعتقد هذا المشهد يغطي طرابلس كلها → يُدرجه لكل المشاريع في المنطقة
الواقع: المشهد في الجزء الشرقي من طرابلس لا يغطي المشاريع في الغرب
```

**الإصلاح:**
```typescript
// ✅ الكود الجديد (صحيح)
// Always compute bbox from geometry (actual scene footprint).
// meta.bbox is a coarse area-level approximation and must NOT be used.
let sceneBbox: number[] = [];
if (meta.geometry?.coordinates?.[0]) {
  const coords = meta.geometry.coordinates[0];
  const lons = coords.map(c => c[0]);
  const lats = coords.map(c => c[1]);
  sceneBbox = [Math.min(...lons), Math.min(...lats), Math.max(...lons), Math.max(...lats)];
}
```

```typescript
// ❌ يجد أول مشهد بنفس التاريخ — قد يكون مشهداً مختلفاً تماماً
```

```typescript
// ✅ يستخدم scene_id المحدد الذي تم تحليله فعلاً
const sceneByDate = new Map<string, string>();
for (const scene of scenes) {
  if (!sceneByDate.has(scene.scan_date)) {
    sceneByDate.set(scene.scan_date, scene.scene_id);
  }
}
const correctSceneId = rec.bundle.scene_id || sceneByDate.get(scanDate) || null;
```

## 4. ملاحظات حول المشاريع نفسها

### 4.1 المشاريع الأربعة هي بيانات تجريبية

جميع المشاريع الأربعة في قاعدة البيانات أُنشئت خلال مرحلة التطوير والاختبار — ليست مشاريع حقيقية.

| المشروع | الكود | الإشكالية |
|---------|-------|----------|
| مشروع طريق السريع الساحلي | — | bbox تجريبي كبير [13.0, 32.85, 13.3, 32.95]، 0 scans |
| طريق الدائري الثالث | RD-TRP-041 | إحداثيات تجريبية، ليست الطريق الحقيقي |
| المستشفى التعليمي | BLD-TRP-027 | bbox 0.11 km² بالقرب من الميناء لا مستشفى |
| محطة الصرف الصحي | UTL-TRP-013 | إحداثيات تجريبية قريبة من الموقع |

**الحالة الآن**: البيانات نظيفة وكل scan يشير لمشهد صحيح. لكن المشاريع نفسها إحداثياتها تقريبية.

### 4.2 المستشفى يظهر في منطقة الميناء (الصورة المرفقة)

من الصورة المرفقة، المشروع "توسعة مستشفى طرابلس التعليمي" يظهر في منطقة الميناء/الساحل (الصندوق الأبيض فوق البحر المرئي). هذا لأن bbox [13.1823, 32.8985, 13.1858, 32.9015] يقع في المنطقة الساحلية لطرابلس، لا في موقع المستشفى التعليمي الحقيقي.

**التوصية**: تحديث إحداثيات هذا المشروع لتعكس الموقع الحقيقي لمستشفى طرابلس التعليمي (المعروف بمستشفى الجلاء) قبل استخدامه للتحليل الجدي.
